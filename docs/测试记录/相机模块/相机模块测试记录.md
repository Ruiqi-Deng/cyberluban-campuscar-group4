**测试环境**：NUC + 工业相机 / Ubuntu / OpenCV / Flask

## 测试内容

海康工业相机在箱体内部的安装与远程触发拍照测试。相机固定于箱体内部，通过Flask服务接收远程指令触发拍照，用于交接留证。


## 测试过程

1. 相机固定于箱体内部，通过USB连接NUC
2. NUC运行Flask服务，监听 `/unlock` 和 `/lock` 接口
3. 外部通过curl发送HTTP请求触发拍照


## 测试结果

**开锁触发拍照：**

POST /unlock → 发送 CTRL,0,0,1,0,0 给 ESP32 → 触发拍照

拍照成功：20260803_150018.jpg

**关锁触发拍照：**

POST /lock → 记录关锁并触发拍照

拍照成功：20260803_150037.jpg

相机在箱体内部正常响应远程指令，开锁和关锁时均成功触发拍照，图片保存至 /home/pc/Pictures/CameraCapture/ 目录。


## 测试结论

相机模块已在箱体内部固定安装，可通过远程HTTP指令触发拍照，开锁/关锁时自动留证，图片保存正常。满足交接留证功能需求。
