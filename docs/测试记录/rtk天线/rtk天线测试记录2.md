# RTK天线模块 实测记录

**测试人员**：陈铭敏 
**测试日期**：2026年8月20日  
**测试环境**：NUC + RTK模块 / Ubuntu / RTK上位机软件  
**所属组别**：算法组  

## 测试内容
RTK天线放置于室外开阔环境，接收真实卫星信号，验证固定解（Fixed）状态下的定位精度及数据输出稳定性。

## 测试过程与结果
将RTK模块连接至上位机，待卫星收敛后，成功获取到高精度定位数据。

**核心数据提取（来自上位机实时信息）：**
*   **经纬度**：经度 `113.476383`，纬度 `22.892306`（准确输出）
*   **定位类型**：`RTK Fixed`（固定解）
*   **可用卫星数**：14
*   **定位精度**：实现厘米级定位（依据GGA帧数据第四项为4/“RTK Fixed”状态判定）

**串口原始数据提取：**
上位机持续输出标准NMEA格式数据，解析正常。截取部分核心报文如下：
> $GNGGA,061500.00,2228.92306,N,11328.58380,E,4,12,1.37,32.4,M,0.0,M,,*7F
> （注：GGA帧中第4个字段为“4”，表示定位类型为RTK固定解）

## 测试结论
*   **A3 RTK定位逻辑验证（室外部分）**：通过。
*   天线已成功接收到卫星信号，并达到了 **RTK Fixed（固定解）** 状态。
*   定位数据能够稳定、准确地输出真实的经纬度坐标，满足了小车厘米级高精度导航定位的需求。
