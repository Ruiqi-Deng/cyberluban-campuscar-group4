# BioShuttle 电子锁 — 组员使用说明

当前固件在 `D:\bioshuttle-sensors`（PlatformIO / ESP32）。  
协议与 `D:\cyber\BioShuttle` 一致，上位机可继续用 `camera_serial.py`。

## 已经跑通什么

- ESP32 收到串口指令后，GPIO5 拉低 800ms 驱动继电器（低电平触发）。
- 本机脚本 `python D:\bioshuttle-sensors\unlock.py` 已成功发出 `CTRL,0,0,1,0,0`，ESP32 回了 `[ACTION] Unlock pulse done`。
- 开发板上 BOOT 键也能开锁，**只用于实验室**，箱子装好后不要依赖按键。

关锁是电磁锁弹簧复位，**没有关锁串口指令**。

## 系统怎么控（装进箱子以后）

```
小程序 / 上位机
    →  POST http://小电脑:5000/unlock
小电脑（NUC）camera_serial.py
    →  USB 串口发送  CTRL,0,0,1,0,0\n
ESP32 GPIO5
    →  继电器
    →  12V 电磁锁开锁 800ms
```

小电脑把 ESP32 当 USB 串口设备。`camera_serial.py` 里改 `SERIAL_PORT`（Windows 如 `COM7`，Linux 如 `/dev/ttyUSB0`），波特率 **115200**。

## 接线

| 功能 | ESP32 | 说明 |
|------|--------|------|
| 继电器 IN | **D5** | 低电平吸合 800ms |
| 门微动开关 | D18 | INPUT_PULLUP，接到 GND 表示门关；可先不接 |
| 锁舌反馈 | D21 | INPUT_PULLUP，接到 GND 表示锁舌缩回；可先不接 |
| 继电器 VCC | VIN（约 5V） | 多数继电器模块要 5V |
| 继电器 GND | GND | 必须和 ESP32 共地 |

12V 锁（确认继电器会咔哒后再接）：

```
12V+  →  继电器 COM
继电器 NO  →  锁正极
锁负极  →  12V-
12V-  →  ESP32 GND（共地）
```

12V **不要**接到 3V3 / D5 / 其它 GPIO。

## 串口协议（给写上位机的同学）

波特率 115200，换行结束。

**开锁（电脑 → ESP32）**

```
CTRL,左轮,右轮,锁,舱盖,拍照
CTRL,0,0,1,0,0
```

第 3 个数字 `1` = 开锁。

**状态（ESP32 → 电脑，约每 500ms）**

```
POS,enc_left,enc_right,lock_state,temperature,humidity,battery
```

`lock_state`：**0 = 已解锁，1 = 锁闭**（以这份 ESP32 固件为准）。

未接反馈线时，D21 上拉可能一直是高/低，`lock_state` 不能当机械到位依据。要以继电器动作或以后接好反馈开关为准。

## 实验室怎么复现

1. VSCode + PlatformIO 打开 `D:\bioshuttle-sensors`，Build → Upload。
2. **关掉 Serial Monitor**（点该终端，`Ctrl+C` 或点垃圾桶），否则 COM 口被占用。
3. 安装一次：`python -m pip install pyserial`
4. 运行：`python D:\bioshuttle-sensors\unlock.py`  
   把脚本里的 `PORT = "COM7"` 改成你电脑设备管理器里的口。
5. 看到 `Unlock pulse done` 且继电器响一声即成功。

桌上调试也可以按 ESP32 的 **BOOT**（不要按 EN/RST）。

## 和温湿度、拍照的关系

- AM2301 已与电子锁合并在同一份固件（`src/main.cpp`）。
- 黄线接 **D27**，3V3 供电，黄线与 3V3 之间加 4.7kΩ 上拉。
- 温度、湿度写入 `POS` 的 temperature / humidity 字段（十分位，如 255 = 25.5℃）。
- 拍照仍由小电脑 `camera_serial.py` 负责。

## 注意

- Serial Monitor 和 Python 脚本不能同时占用同一个 COM 口。
- 这份工程路径必须是英文（`D:\bioshuttle-sensors`），不要放在 `D:\vscode文件` 这类中文目录，否则 ESP32 工具链会编不过。
